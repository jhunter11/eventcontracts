# eventcontracts (Python)

This is the Python workspace for the event-contracts research framework.

The full project README — covering layout, dual-language strategy, and
roadmap — lives at the repository root: [`../README.md`](../README.md).

## Quick Start

From the repository root:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install --upgrade pip
python3 -m pip install -r python/requirements-dev.txt
make quality
```

## Editable Install

```bash
python3 -m pip install -e ./python
```
