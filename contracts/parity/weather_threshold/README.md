# Weather Threshold — Parity Fixture

`parity_cases.parquet` is generated by the Phase 4 bundle exporter
(see `docs/implementation-roadmap.md`) from a deterministic replay
window over Kalshi weather markets joined with NWS observations.

This directory is currently a placeholder. The fixture is intentionally
not committed until:

1. The Kalshi capture path persists raw envelopes to Parquet
   (Phase 1).
2. The normalization pipeline emits `QuoteEvent`, `TradeEvent`,
   `LifecycleEvent`, and `ExternalSignalEvent` deterministically
   (Phase 1).
3. The feature builder produces a `FeatureVector` matching
   `../examples/weather_threshold/feature_schema.json` (Phase 2).
4. The paper executor closes out each case and reports the PnL
   delta (Phase 3).

Until then, both the Python and Rust parity loaders should treat the
absence of this file as an explicit "no parity coverage yet" signal,
not an error.

Schema for the eventual Parquet file is documented in
`../../schemas/parity_cases.parquet.schema.md`.
